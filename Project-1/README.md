# 🤖 React Basics Chatbot

An interactive chatbot built with React to demonstrate core React concepts and UI interactions. This project features a simple chat interface, message persistence, and component-driven design—perfect for learning React fundamentals.

## ✨ Features

- **Interactive Chat UI**: Send and display messages with a conversational layout
- **Persistent Messages**: Session storage persistence for chat history across reloads
- **Modular Components**: `UserInput`, `ChatMessage`, and `Message` components for clear separation of concerns
- **Simple State Management**: Local component state using React hooks

## 🛠️ Tech Stack

- **React 19**
- **Vite**
- **CSS** for styling
- **ESLint** for code quality

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/your-username/learning-react.git
   cd learning-react/Project-1
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start development server**

   ```bash
   npm run dev
   ```

4. Navigate to the link given
