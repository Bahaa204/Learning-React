# Learning React

A comprehensive collection of React projects built during my journey to master React development. This repository showcases progressive learning from basic concepts to advanced features like routing, context API, external APIs, and AI integration.

## 📋 Projects Overview

### 🤖 Project 1: React Basics Chatbot

A conversational chatbot designed to help beginners learn React fundamentals.

- **Features**: Interactive chat interface, React concepts explanations
- **Tech Stack**: React, Custom chat components
- **Location**: [`Project 1/`](Project-1/)

### 🎬 Project-2: Movie Discovery App

A React application for browsing and managing favorite movies using The Movie Database (TMDb) API.

- **Features**: Movie search, detailed movie cards, favorites management, responsive design, API calls
- **Tech Stack**: React, React Router, Context API, TMDb API
- **Location**: [`Project-2/`](Project-2/)

### 🍳 Project-3: CookLab

This project is a port to react of a project developed as part of the **COSC333-Web Programming** course at RHU University in Lebanon.
**Repository**: [CookLab](https://github.com/Bahaa204/CookLab.git)

- **Features**: Recipe browsing, AI integration, contact forms, multi-page navigation
- **Tech Stack**: React, React Router, Google Generative AI
- **Location**:
  - [`(React) Project-3/`](Project-3/)
  - [`(Old) CookLab`](https://github.com/Bahaa204/CookLab.git)

## 🛠️ Technologies Used

- **Frontend Framework**: React 19
- **Build Tool**: Vite
- **Routing**: React Router DOM
- **State Management**: React Context API
- **Styling**: CSS Modules
- **APIs**: TMDb API, Google Generative AI
- **Linting**: ESLint

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation & Running

1. **Clone the repository**

   ```bash
   git clone https://github.com/your-username/learning-react.git
   cd learning-react
   ```

2. **Navigate to a project directory**

   ```bash
   cd Project-2  # or Project-3 or Project-1
   ```

3. **Install dependencies**

   ```bash
   npm install
   ```

4. **Start the development server**

   ```bash
   npm run dev
   ```

5. **Open your browser** and navigate to the link shown or press `o` then `enter` in the terminal
